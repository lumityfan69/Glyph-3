# Glyph-3
Glyph-3 is a language similar to Morse code but Glyph-3 is more accessible only needing you to be able to see and move your eyes to use Glyph-3, but it can also be written out like normal. in order to use Glyph-3 with only eyes there are a few rules, 1: ( = look to the left, 2: ) = look to the right, 3: / = look up, 4: // = look down. but you need to learn what these mean in the code first so use my translator to help.
